Deepwater Horizon Interactive HTML Presentation

طريقة التشغيل:
1) فك الضغط عن الملف.
2) افتح index.html مباشرة في المتصفح.
3) استخدم أزرار التنقل أو أسهم لوحة المفاتيح.
4) اضغط على النقاط البرتقالية داخل الشرائح لاستعراض تلميحات تفاعلية.
5) زر ⛶ لتشغيل العرض بملء الشاشة.
6) زر ☰ لفتح ملاحظات الشريحة.

الملفات:
- index.html: العرض التفاعلي الكامل.
- assets/: صور الشرائح المستخرجة من ملف PDF.

ملاحظة:
يمكنك رفع المجلد كاملًا على GitHub Pages أو Netlify لمشاركة العرض كرابط.
